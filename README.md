# The-spot
A simple marketplace web app for learners to sell second-hand items.

## How to use

1. Open `index.html` in your browser.
2. Fill in the item details and click **Post Item**.
3. The listing appears immediately and is stored locally in your browser.

## Files

- `index.html` — main page and listing form
- `styles.css` — user interface styling
- `script.js` — data management and rendering logic
